# Power BI Sales Dashboard — Build Guide

## Data
Load `../excel-sales-analysis/data/sales_data.csv` into Power BI Desktop.

## Measures
Use the DAX measures in `DAX_Measures.txt`.

## Layout
1. Four KPI cards: Total Sales, Total Orders, Total Quantity, Average Order Value.
2. Monthly Sales Trend line chart.
3. Sales by Region column chart.
4. Sales by Category donut/column chart.
5. Top Products bar chart.
6. Slicers: Region, Category, Product, Order Date.

## Business Questions
- Which region generates the most sales?
- Which category contributes the most revenue?
- Which products drive sales?
- How does revenue change over time?

## Validation
Expected headline KPIs from the supplied dataset:
- Total Sales: 450,350
- Total Orders: 24
- Total Quantity: 142
- Average Order Value: 18,764.58

The `.pbix` file should be created and validated in Power BI Desktop before being presented as a completed Power BI deliverable.
