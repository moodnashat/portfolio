# 🗄️ SQL Data Analysis

## Objective
Answer practical business questions from a relational dataset using SQL.

## Planned Analysis
- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- CASE expressions
- JOINs
- Subqueries and CTEs
- Ranking and trend analysis
- Business-focused analytical questions

## Deliverables
- SQL query collection
- Dataset/schema description
- Business questions and answers
- Key findings

> Queries and findings will be based on the actual dataset used in the project.
