# 🗄️ SQL Sales Data Analysis

A business-focused SQL project using the same sales dataset as the Excel, Power BI, and Python projects.

## 🎯 Business Questions

1. What are total sales, orders, and units sold?
2. Which region generates the most revenue?
3. Which category performs best?
4. Which products contribute the most revenue?
5. How does sales change by month?
6. What is the average order value?

## 🛠️ SQL Skills

- SELECT / WHERE / ORDER BY
- SUM / COUNT / AVG
- GROUP BY
- Date extraction
- Business aggregations
- Reusable analytical queries

## 📁 Files

- `queries/sales_analysis.sql` — core analysis queries
- Source data: `../excel-sales-analysis/data/sales_data.csv`

## 📊 Reference Results

The shared dataset produces **450,350 total sales**, **24 orders**, **142 units**, and an **18,764.58 average order value**.

## 💼 Interview Angle

The queries are intentionally written around business questions rather than syntax exercises, making it possible to explain both the SQL and the decision the query supports.
