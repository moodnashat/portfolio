# Excel Analysis Guide

Use `../data/sales_data.csv` as the source dataset.

## Recommended KPIs

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

## Recommended PivotTables

1. Sales by Region
2. Sales by Category
3. Sales by Product
4. Monthly Sales Trend

## Recommended Dashboard

Create KPI cards for Total Sales, Orders, Quantity, and Average Order Value. Add charts for monthly sales, regional performance, and product/category contribution.

## Data Integrity

`Sales` is calculated as `Quantity × Unit_Price`. The dataset is intentionally small so the analysis can be reproduced and explained during an interview.
